# Mission 0 - Create your GitHub workspace

## 1. Task / objective
Create a correctly named repository and prepare a clear folder structure for all missions.

## 2. Work completed
- Created a project folder called digital-detective-8030 on my computer.
- Inside it I made one folder for each mission (mission-00-setup up to mission-08-final-report) and an evidence folder for screenshots and outputs.
- Added a README.md in the main folder and in every mission folder.
- Created an empty number_converter.py inside mission-05-numbers-data, which I will use in Mission 5.
- Checked that Python 3 and Git are installed.
- Created a public GitHub repository with the same name, digital-detective-8030, and pushed my folder to it.

## 3. Commands / tools used
- mkdir: used to create the project folder and the mission folders.
- cd: used to move into my project folder.
- pwd: used to check which folder I was currently in.
- touch: used to create the empty README files and number_converter.py.
- ls: used to list the folders and files and confirm everything was created.
- open: used to open my README file in a text editor.
- python3 --version: shows the installed Python version. Mine showed: Python 3.14.7
- git --version: shows the installed Git version. Mine showed: git version 2.54.0 (Apple Git-157)

## 4. My understanding
A repository is a project folder that stores all the files of a project and keeps track of every change made to them. When it is published on GitHub, there is also a copy online, so the work is backed up and easy to share. I organised my repository with one folder for each mission so that each mission's work and README stay together and are easy to find. This also matches the rule that every mission is committed separately, so my progress is clear in the commit history.

## 5. Difficulties faced

## 6. How I resolved them
I replaced the long dashes with normal hyphens, and I switched to VS Code for editing my README files.
