# Mission 1 - Know your computer

## 1. Task / objective
To explain how a computer takes input, processes it, produces output and stores data (IPOS), and to identify hardware, software and computer systems around me.

## 2. Work completed
I traced one activity through the IPOS stages, listed hardware and software I use and classified them, and listed three computer systems from everyday life.

## 3. Commands / tools used
No Terminal commands were needed for this mission. I used VS Code to write this README.

## Task 1.1 - IPOS trace
Activity: typing a document and saving it.

| Stage | What happens in my example | Hardware / component |
|---|---|---|
| Input | I type letters on the keyboard and the computer receives each key press. | Keyboard |
| Processing | The CPU works out which character each key press is and the memory holds the text while I work. | CPU and memory |
| Output | The text appears on the screen as I type. | Screen |
| Storage | When I save, the file is written so I can open it later. | SSD |

## 4. My understanding
A computer works in four steps: input, processing, output and storage. Input is how data gets into the computer, for example typing on the keyboard. Processing is when the CPU and memory work on that data. Output is the result I can see or hear, such as text on the screen. Storage keeps the data saved on the SSD so I can use it again later. I understood this by following one activity, typing and saving a document, through all four stages.
