## Task 6.1 – Understand the basic Git workflow

| Git operation | What it does in my own words |
|---|---|
| Check repository status | `git status` shows which files are modified, staged or untracked. |
| Stage selected changes | `git add filename` selects a file to include in the next commit. |
| Create a commit | `git commit -m "message"` saves the staged changes with a description. |
| View commit history | `git log --oneline` displays previous commits in a short format. |

### Difference between staging and committing

Staging means selecting the changes that I want to save. Committing means recording those staged changes in the local Git repository.
