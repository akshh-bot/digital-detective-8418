## 5. Task 4.2 – Compare compiler and interpreter

| Point | Compiler | Interpreter |
|---|---|---|
| When translation / execution happens | Translates the program before execution | Executes instructions at runtime |
| Typical output | Produces compiled code or an executable | Executes the program without normally creating a standalone executable |
| One example | C compiler (GCC) | Python interpreter |
| One advantage | Generally provides faster execution | Makes testing and debugging easier |

**Explanation:**

A compiler translates the source code into another form, often machine code, before the program runs. An interpreter executes a program by reading and carrying out its instructions at runtime. Compiled programs generally execute faster, while interpreted execution makes testing and debugging easier. Both are used to translate programming instructions into actions the computer can perform.
