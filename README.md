assignment focused on understanding computers,
operating systems, programming, networking and
version control through practical activities.

- Computer fundamentals and IPOS

- Operating systems, files and permissions
- Compilers and interpreters

- Python programming
- Git and GitHub
- Computer networks, DNS and protocols
- Client-server communication

## How to Run the Number Converter

1. Open Terminal.
2. Navigate to the converter folder:

   cd mission-05-numbers-data

3. Run the Python program:

   python3 number_converter.py

4. Follow the instructions displayed by the program.
